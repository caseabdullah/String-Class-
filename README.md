# 🔤 Custom String Class Using Dynamic Memory Allocation | C++

## 📌 About the Project

This project implements a custom **String class in C++** using dynamic memory allocation and character arrays.

The purpose is to understand how strings work internally and how to manage memory manually without relying on the built-in `string` class.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Dynamic Memory Allocation
  - Pointers and Character Arrays
  - Constructors and Destructors
  - Copy Constructor
  - Operator Overloading
  - Deep Copy and Memory Management

## ⚙️ Implemented Features

### 1. String Construction & Memory Management
- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Destructor
- Resize Function

### 2. Operator Overloading
- Assignment Operator (`=`)
- Concatenation Operator (`+`, `+=`)
- Comparison Operators (`==`, `!=`, `<`, `>`, etc.)
- Subscript Operator (`[]`)
- Input and Output Operators (`>>`, `<<`)

### 3. String Manipulation
- Insert
- Remove
- Replace
- Substring
- Find
- String Length

### 4. Number Conversion
- Convert numbers into strings
- Handle integer and decimal values

## 🧠 Key Learning Outcomes

- Understanding internal string implementation.
- Managing dynamic memory using `new` and `delete[]`.
- Implementing deep copy to avoid shallow copying.
- Understanding operator overloading.
- Handling pointers and character arrays.
- Preventing memory leaks and dangling pointers.
- Developing reusable classes using OOP principles.
